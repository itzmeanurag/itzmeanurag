- Embedding models: **nomic-embed-text · Titan Embeddings V2 · BGE · all-MiniLM**
- RAG evaluation: **LLM-as-judge · groundedness scoring · semantic caching**

### 🤖 LLM Orchestration
- **LangChain** (Python) · **LangChain4j** (Java) · **Spring AI**
- **Amazon Bedrock** (Claude · Mistral · Titan) · **Ollama** (local inference)
- Prompt engineering: **12-template PromptAssembler · persona injection · guardrail rules**
- Memory systems: **3-layer buffer/summary/facts · persistent sessions**

### 🛡️ AI Safety & Guardrails
- Content safety: **6-category filtering** (sexual · violence · hate · insults · misconduct · prompt injection)

- Model governance: **SHA-256 checksums · pickle detection · supply chain validation**
- **AWS Bedrock Guardrails** — cloud-native safety at scale

- **QLoRA** — fine-tune 7B models on consumer hardware (6GB VRAM)
- **LoRA adapters** — PEFT, bitsandbytes, Hugging Face Transformers
